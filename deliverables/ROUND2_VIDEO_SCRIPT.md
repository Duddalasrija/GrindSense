# GrindSense Round 2 video script (90 seconds maximum)

Use this as a shot plan, not as a claim that the work is already complete. Replace every bracketed item with an actual screen recording or CAD view before recording the final take. If the CAD is still unfinished, say so and show the current CAD progress honestly.

| Time | Picture | Narration |
|---|---|---|
| 0–10 s | Team/title card and mixer-grinder | “We are Team [team name]. GrindSense explores outcome-based grinding: the user chooses a texture, and the system responds to the estimated grinding state.” |
| 10–25 s | Show the current mesh-based CAD concept only if it opens reliably; otherwise show the annotated concept graphic and label it as an illustration | “This is early visual concept progress. The SolidWorks parts are imported mesh bodies; they are not yet editable feature-based parts or a mated assembly. Sensor locations are proposals, not installed hardware.” |

| 52–70 s | Live chart, adaptive event or one controlled warning scenario | “The simulation demonstrates how adaptive responses and warning or stop events could be presented. This is not a measurement from a physical grinder and does not validate real safety limits.” |
| 70–82 s | Results and session history | “The session records its estimated outcome and event history so the user can review and compare runs.” |
| 82–90 s | Current hardware/CAD status and next step | “Next we will complete and review the CAD, then plan hardware integration and validate the sensing and control loop on a physical prototype.” |

## Recording rules

- Keep total export length at **90 seconds or less**.
- Use actual capture from the running app and SOLIDWORKS. Avoid static mockups presented as live behavior.
- Keep “SIMULATED” visible whenever the dashboard telemetry is shown.
- Do not name components as procured unless the team has actually purchased them.
- If a shot cannot be captured, shorten or remove it rather than inventing progress.
- Review the complete exported video once for audio, legibility, timing, and factual accuracy.
