# GrindSense concept CAD

## Required CAD files

- `MotorHousing.SLDPRT` — motor housing concept.
- `MixerJar.SLDPRT` — mixer jar concept.
- `BladeAssembly.SLDPRT` — blade assembly concept.
- `Lid.SLDPRT` — lid concept.
- `GrindSense_Concept_Assembly.SLDASM` — overall visual concept document.
- `GrindSense_Exploded_Concept.stl` — separated layout for an exploded view.
- `GrindSense_Concept_Annotated.svg` — visual concept with proposed sensor locations.

Open the `.SLDASM` in SolidWorks and press **F** to fit the view. All four part documents were saved in SolidWorks from STL imports. They contain graphic mesh bodies, not editable feature-based solids. The assembly document still holds the combined visual concept as one fixed component; the four part documents have not yet been assembled and mated together, and an exploded configuration and SolidWorks screenshots are not included.

All dimensions and sensor locations are illustrative. This is a visual progress prototype, not a validated or manufacturing-ready design.
