# GrindSense concept CAD

This folder contains the current SolidWorks visual concept for the Round 2 progress prototype.

## Files to open

- `GrindSense_Concept_Assembly.SLDASM` — SolidWorks assembly document for the overall visual concept.
- `GrindSense_Concept_Model.SLDPRT` — combined assembled concept mesh saved in SolidWorks.
- `MotorHousing.SLDPRT` and `MixerJar.SLDPRT` — separate imported concept mesh parts.
- `GrindSense_Exploded_Concept.stl` — separated component layout for an exploded view.
- `GrindSense_Concept_Annotated.svg` — concept illustration with proposed sensor locations.

Open the `.SLDASM` in SolidWorks and press **F** for Zoom to Fit. The STL-derived bodies are graphic mesh bodies, not editable feature-based solids. The assembly currently contains the combined concept as one fixed component; it is not a mated assembly of separate parts. A separate blade part, lid part, named exploded configuration, and SolidWorks screenshots are still outstanding. Dimensions and sensor positions are illustrative only; this is not a validated or manufacturing-ready design.
